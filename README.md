# Practically Paradise

Official landing page for Practically Paradise - An atmospheric, animated web experience that captures the band's aesthetic with floating ash particles and flickering neon.

## ✨ Features

- **Floating Ash Animation**: 50+ dynamically generated particles that drift upward with randomized trajectories
- **Flickering Neon Band Logo**: Custom neon sign effect with realistic flickering animation
- **Dark Atmospheric Background**: Deep blue/teal gradient creating an immersive, moody atmosphere
- **Custom Typography**: "Absolute Neon" script font for that authentic neon aesthetic
- **Fully Responsive**: Seamless full-viewport experience across all devices
- **Lightweight**: Pure CSS animations for optimal performance

## 🚀 Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

## 🎨 Tech Stack

- **React** - UI library
- **Vite** - Build tool and dev server
- **CSS3** - Custom animations and styling
- **JavaScript** - Dynamic particle generation

## 🎭 Animations

- **Ash Particles**: Continuous upward drift with rotation (5-11s duration)
- **Text Flicker**: 3-second looping neon flicker effect with varying opacity and glow
- **Background**: Static gradient for optimal performance
